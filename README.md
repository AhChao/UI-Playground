# Vue 3 + Vite 任務管理 Playground

這是一個使用 Vue 3 和 Vite 構建的任務管理應用程式，旨在作為 UI 整合測試的練習環境。

## 功能特色

- **任務管理**：建立、編輯、刪除和檢視任務詳情
- **拖放排序**：使用 `vuedraggable` 輕鬆重新排列任務
- **篩選與排序**：依狀態、優先級篩選，或依截止日期、建立日期排序
- **標籤系統**：支援多選標籤與自動完成
- **除錯面板**：模擬 API 延遲、錯誤和權限控制
- **多語言支援**：繁體中文 (zh-TW) 與英文 (EN) 切換

## 快速開始

### 安裝依賴

```bash
npm install
```

### 啟動開發伺服器

```bash
npm run dev
```

### 建置生產版本

```bash
npm run build
```

# Vue 3 + Vite Task Manager Playground

This is a Task Manager application built with Vue 3 and Vite, designed as a playground for UI integration testing.

## Features

- **Task Management**: Create, edit, delete, and view task details
- **Drag & Drop**: Easily reorder tasks using `vuedraggable`
- **Filtering & Sorting**: Filter by status, priority, or sort by due date, created date
- **Tag System**: Support for multi-select tags with auto-complete
- **Debug Panel**: Simulate API latency, errors, and permission controls
- **i18n Support**: Switch between Traditional Chinese (zh-TW) and English (EN)

## Getting Started

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
